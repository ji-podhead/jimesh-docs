## Architecture Summary

## Areas to Research

### 1. Entropy-Based Request Routing
Our approach: Two-phase request. Phase 1: send request with logprobs to cheap model, calculate avg normalized Shannon entropy (H/log2(k), k=5 unique tokens), threshold 0.45. Below threshold → keep cheap model. Above → escalate to expensive reasoning model. Only non-streaming requests. Self-call to proxy's own /v1/chat/completions for phase 1.
Questions: Is Shannon entropy on logprobs the right metric? Industry alternatives? Better entropy measures for LLM routing? Existing repos for logprob-based routing? Papers beyond arXiv:2605.22873?

### 2. Model Role Schema (7 roles)
We define 7 roles: routing, utility, coding, reasoning, vision, aggregation, gating. Each maps to a model. Chain-scoped overrides. Resolution: chain → global → catalog heuristic.
Questions: Is 7 roles right? Industry standard role taxonomies? How do LangGraph, CrewAI, AutoGen, OpenAI Swarm define agent roles? Better role classification?

### 3. MoE Expert Pipeline (Mixture of Agents)
Our approach: Gating model classifies task → selects experts → parallel (goroutines) or sequential (context passing) → LLM synthesis aggregation. 3 seed experts: Coder (coding role), Reviewer (reasoning role), Researcher (utility role). SSE streaming events: gating_start → gating_done → expert_start → expert_done → synthesis_start → complete.
Questions: How does this compare to MoA (arXiv:2406.04692), CrewAI, AutoGen, LangGraph? Better aggregation methods? Gating model best practices? Should we use CrewAI/LangGraph instead of custom Go? Reference repos for MoA implementation?

### 4. Orchestration with Role-Based Mesh Routes
POST /api/orchestrate SSE stream. Go structs: AgentRole, RouteMapping, Task, TaskResult, WorkflowState. Parallel/sequential execution. Tasks resolve model from role schema.
Questions: Industry orchestration patterns? How do Temporal, Airflow, Dapr workflow compare for LLM orchestration? Is SSE the right transport or should we use WebSocket/Server-Sent GraphQL? Better task dependency resolution?

### 5. Model Stats Enrichment Pipeline
4 stages: (1) OpenRouter API for static facts (context, pricing, modality), (2) Artificial Analysis for benchmarks (MMLU, HumanEval), (3) SearXNG + utility model extraction as fallback, (4) Levenshtein fuzzy dedup across same-class model variants.
Questions: Better data sources? How do lmarena.ai, HuggingFace leaderboard, Artificial Analysis do it? Existing model evaluation frameworks? Better fuzzy matching than Levenshtein? Should we use HuggingFace's evaluation-harness? Reference repos?

### 6. SSH Tunnel Bridge (Go as proxy, not browser)
Browser → HTTP/3 → JiMesh Go backend → SSH tunnel → remote target. Go holds persistent SSH sessions per project. Reverse proxy cache for iframe content. WebSocket/SSE through tunnel for terminal/logs.
Questions: Is this the right pattern? How do VS Code Remote, Coder, Gitpod, ttyd handle browser-to-remote? Better SSH tunnel libraries in Go? Should we use frp, ngrok-like, or WireGuard instead? HTTP/3 reverse proxy repos in Go?

### 7. E2E Deployment Engine (auto-generate Dockerfiles + compose)
Schema-driven: base medium (terminal/dsh/opencode) + addons (claude-code, aider, jimesh-mesh) + user overrides → Go text/template generates Dockerfile, docker-compose.yml, config files (opencode.json, vconfig.json). SSH write to target → docker compose up.
Questions: How do DevPod, DevContainer, Coder templates, Pulumi, Terraform do this? Better template engines? Should we use DevContainer spec? Existing Dockerfile generators? Schema validation libraries?

### 8. Docker MCP Toolkit Integration
JiMesh as MCP server (expose API as tools via mcp-go) + MCP client (discover other MCP servers via Docker MCP Gateway). docker mcp server list → auto-register as agent tools. Connectors: filesystem, postgres, github, brave-search, puppeteer, docker.
Questions: Is Docker MCP the right approach vs custom tool registry? How does Docker MCP Toolkit work exactly? Is mcp-go (mark3labs) the best Go MCP SDK or is there an official one? MCP vs OpenAI function calling vs LangChain tools — which standard? Reference MCP server repos?

### 9. Container/Environment Registry
Compose environment once (base image + packages + config) → template in DB → instantiate as Docker container. Pre-built: Python+CrewAI, Go+DSH, Node+Claude, Terminal, Adminer. Agent can create template → instantiate → run → destroy. Docker API client.

### 10. Auto-Discovery (containers + ports + apps + MCP)
