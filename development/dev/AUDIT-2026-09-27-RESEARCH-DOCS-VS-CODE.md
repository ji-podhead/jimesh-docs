# AUDIT 2026-09-27 — Research Docs (`docs_dev/research/R*.md`) vs Real Code

**Method:** each of the 18 R-numbered files under `docs_dev/research/` was read in full (or to the
point its concrete technical claims were identified), then every named symbol/type/route/table/
component was grepped for in `src/backend/**/*.go` and `src/frontend/src/**/*.tsx`. Classification
is based on what the grep found in the actual source tree, not on what `docs_dev/backlog/BACKLOG.md`
says. Where BACKLOG.md's own status text contradicts the code, that is flagged explicitly.

**Legend:** NOT BUILT = grep found nothing relevant · PARTIALLY BUILT = some real pieces exist, some
don't (named) · BUILT = concept substantially implemented · SUPERSEDED = a different real approach
replaced what the doc proposed.
