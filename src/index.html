Gateway (live) fetches OpenAPI 3.0.3 directly from the running Go backend — GET http://<host>:19091/openapi.json (unauthenticated, GET only). There is intentionally no bundled fallback copy; if the gateway is unreachable the loader reports the real fetch error.

Auth API and Admin API render the bundled enterprise specs from spec/api/*.openapi.json. If pages are served under a sub-path, relative spec/ URLs resolve correctly by design.
